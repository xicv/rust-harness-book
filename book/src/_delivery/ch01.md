# 第 1 章代码包 / Chapter 1 code pack

这个包对应第 1 章结束时的完整 Workspace。它保留第 0 章的离线回合，并加入
只读工具链诊断命令 `--doctor`。

- 源 commit：`decef67c89afba8e4eb095b0c16454e4aca97eb5`
- [下载 ZIP](https://xicv.github.io/rust-harness-book/downloads/ch01/rust-harness-ch01.zip)
- [下载 SHA-256](https://xicv.github.io/rust-harness-book/downloads/ch01/rust-harness-ch01.zip.sha256)

下载后，先核对校验值，再解压：

```sh
shasum -a 256 rust-harness-ch01.zip
unzip rust-harness-ch01.zip
cd rust-harness-ch01
```

然后运行包内记录的验证命令：

```sh
cargo test --workspace --locked
cargo run -p harness-cli --locked -- --doctor
```

当固定工具链处于活动状态时，第二条命令的标准输出必须与包内
`expected-output.txt` 完全一致。

> Request 构建只证明候选产物可以生成和验证，不证明它已经发布。
