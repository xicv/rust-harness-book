# 第 0 章代码包 / Chapter 0 code pack

这个包对应第 0 章结束时的完整 Workspace：一个确定性的离线 Harness 回合、
五个有序事件、CLI 适配器和行为测试。

- 源 commit：`3fed46defa0189e4e1a8f5b7dc3ab61743209b08`
- [下载 ZIP](https://xicv.github.io/rust-harness-book/downloads/ch00/rust-harness-ch00.zip)
- [下载 SHA-256](https://xicv.github.io/rust-harness-book/downloads/ch00/rust-harness-ch00.zip.sha256)

下载后，先核对校验值，再解压：

```sh
shasum -a 256 rust-harness-ch00.zip
unzip rust-harness-ch00.zip
cd rust-harness-ch00
```

然后运行包内记录的验证命令：

```sh
cargo test --workspace --locked
cargo run -p harness-cli --locked -- hello
```

第二条命令的标准输出必须与包内 `expected-output.txt` 完全一致。
