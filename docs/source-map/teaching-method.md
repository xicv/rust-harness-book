# Teaching-method map / 教学方法地图

## Strengths retained from the reference material

- Explain the design idea behind a feature.
- Return to first principles such as memory, values, and interfaces.
- Learn through useful projects before every detail is mastered.
- Use a learning → building → reflection loop.
- Compare concepts with other languages.
- Read production source code.
- Treat testing and architecture as learning tools.
- Grow a primitive whole through progressive architecture.

## Improvements for this project

- Add Red → Green TDD to every chapter.
- Keep all displayed code tied to tested source.
- Use one cumulative harness instead of unrelated projects.
- Add AI review and verification cards.
- Pin modern sources and toolchains.
- Keep comparisons current and fair.
- State uncertainty and non-goals clearly.
