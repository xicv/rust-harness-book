# Source and rights policy / 来源与版权规则

## Clean-room rule

The new book must be original in structure, prose, diagrams, exercises, and
examples.

Reference books may guide:

- topic coverage;
- teaching strengths and weaknesses;
- historical gap analysis;
- learning-method design.

They must not be used as text or asset libraries.

## Codex use

- Pin the exact repository commit.
- Cite exact paths.
- Use short excerpts only when needed.
- Prefer architectural explanation and independently written teaching code.
- Separate source fact from our inference.
- Preserve Apache-2.0 attribution for any copied Codex code.

## Source note types

Every factual technical claim should be marked internally as one of:

- official documentation;
- pinned source code;
- reference-book observation;
- project decision;
- author inference;
- experiment result.

## Asset rule

Do not add an external diagram, screenshot, font, or illustration until its
licence and attribution are recorded.

## Current repository rights status

The original software and source code are available under the MIT License in
the repository-root `LICENSE` file.

The original book prose and diagrams are separately available under the MIT
License in the repository-root `LICENSE-BOOK` file. Keeping the scopes separate
makes it clear which licence travels with a code-only chapter pack.

Third-party excerpts, assets, fonts, and source snapshots retain their own
licences and attribution requirements. Neither project licence overrides those
terms.

## Publication gate

Before publication, confirm that the release records separate rights for:

- original book prose and diagrams (`LICENSE-BOOK`);
- original source code (`LICENSE`);
- third-party excerpts and assets.
